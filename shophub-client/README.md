# ShopHub

A full-stack e-commerce platform built with ASP.NET Core 10 and React.

---

## Features

### Customer

- User Registration & Login
- JWT Authentication
- Product Catalog
- Search
- Filtering
- Sorting
- Shopping Cart
- Checkout
- Order History
- User Profile

### Admin

- Dashboard
- Product Management
- Category Management
- Order Management
- Statistics

---

## Tech Stack

### Backend

- ASP.NET Core 10
- Entity Framework Core
- SQL Server
- Clean Architecture
- Repository Pattern
- JWT Authentication

### Frontend

- React 19
- TypeScript
- Vite
- Tailwind CSS
- TanStack Query
- Zustand

## Installation

### Backend

```bash
cd ShopHub.API

dotnet restore

dotnet ef database update

dotnet run
```

### Frontend

```bash
cd shophub-client

npm install

npm run dev
```
